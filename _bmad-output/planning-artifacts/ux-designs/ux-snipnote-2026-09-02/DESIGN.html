Brand & Style

The editor you keep meaning to build — lightweight, local, calm beside the terminal. Directly references localeditor.app at your request: minimal chrome, content-first, no IDE heaviness, no cloud. Posture is local-first quiet confidence — files stay where they are (plain .md), UI stays out of the way. If LocalEditor's line is “Not every file needs an IDE,” snipnote's echo is “Not every Markdown file needs Obsidian — especially the ones Claude just wrote.”

Inherits LocalEditor aesthetic wholesale: white editor, faint sidebar gray, hairline borders, neutral sans, black primary for the single decisive action. All unlisted components inherit minimal defaults.

Colors — Monochrome + one link blue

Lifted from LocalEditor screenshots (white canvas, #F8F8F9 sidebar, #EAEAEA hairlines, black primary, muted #6B7280).

  • Background / Foreground — Editor canvas, max contrast, no tint (LocalEditor renders markdown like a real page on white).
  • Sidebar — Touch darker than editor, 1px border right. Light gray, not strong contrast.
  • Muted — File tree secondary, Status Bar, Library. Quiet gray exactly as LocalEditor file list.
  • Primary black — Single decisive action (Open Vault). Not a brand color, just contrast.
  • Accent #F3F4F6 — Active File Highlight + hover row only. Never for buttons/banners.
  • Link #2563EB — Only chromatic token. All other chrome achromatic.

Avoid: saturated navs, gradients, colored sidebars, more than one chromatic token, Mote dark #0a0a0a + orange.

Elevation & Depth — Almost flat

Like LocalEditor, hierarchy from background contrast (white vs #F8F8F9) and hairlines, not shadows.

  • Flat (0): Editor, Sidebar, File Tree rows, Tab Bar, Status Bar — flat with borders.
  • Raised (1): Command palette ⌘P — white + 12px radius + 0 8px 32px rgba(0,0,0,.08) + 0 1px 2px rgba(0,0,0,.06). Only elevated surface in v1. Matches LocalEditor's Jump to anything… palette.
  • Banner (inline): Under Tab Bar, muted + border, no shadow.

Shapes — Softly rectangular

  • rounded/sm 6px — Search input, inline code, Library sort, banner
  • rounded/md 8px — Active Highlight row, palette result row, new-note button
  • rounded/lg 12px — Palette shell, dialogs (Open Vault)
  • rounded/full 9999px — Only for future pills/dots, not v1
