Interaction Primitives — Keyboard-first

Like LocalEditor's ⌘K/⌘⌥S discipline, scoped to v1. Mouse is fallback.

  • ⌘P / Ctrl+P — Focus Search / open Palette (filename). Esc closes → focus Editor. The ⌘K equivalent for snipnote v1.
  • ↑ ↓ Enter Esc — Palette nav
  • Click — File Tree row opens Note; Tab Bar + creates; Library opens menu
  • ⌘S — Save (also auto-save 500ms debounce [ASSUMPTION]); no unsaved dot — atomic temp+rename
  • ⌘W — Close window (persists vault/tabs)
  • Back/Forward in Tab Bar — Session history only [ASSUMPTION]

Mouse: click to act; no drag-to-reorder, no drag-to-move file, no multi-window v1, no full-text search v1, no slash palette v1, no floating Scratchpad ⌘⌥S (LocalEditor, defers to v5), no collaborative cursors. Hover shows {colors.accent}. Editor scroll native.

Banned everywhere: everything above — keeps v1 honest for first dollar.

Accessibility Floor — Behavioral

Visual contrast lives in DESIGN.md — light monochrome #0F0F0F on #FFFFFF meets AA; tokens verified.

  • WCAG 2.2 AA across desktop window. All chrome meets AA against its token.
  • Tab order: Sidebar Search → File Tree (roving tabindex per row) → Library → Tab Bar + → Editor → Status Bar (skip). Esc always returns to Editor or closes palette/banner.
  • Screen reader: “Vault {folder}, {N} notes.” Rows: “Note {name}” / “Folder {name}, collapsed/expanded, {N} items.”
  • Palette fully keyboard-operable; results announce via aria-live as filter changes.
  • Focus rings {colors.ring} #0F0F0F 2px offset, AA against background+sidebar.
  • Editor contenteditable preserves heading hierarchy for AT (h1/h2), links as links, code as code.
  • No traps. Native Tauri traffic lights OS-accessible.

Inspiration & Anti-patterns

  • Lifted from LocalEditor.app: “A lightweight, local editor for the files your agents write” / “Not every file needs an IDE.” Plain-folder Vault (no import), light palette, centered 760px reading width, file-type readable views (v1 Markdown only), no sync by principle (“No, and it never will”), ⌘K-style palette (Jump to anything… → snipnote ⌘P), “Projects/notes/Architecture.lcv” density. Pokedex.md status/tags/updated property panel informs future YAML/frontmatter but v1 preserves frontmatter as text [ASSUMPTION].
  • Lifted from Obsidian: Plain .md on disk, file-system truth, vault as folder, Active Highlight.
  • Rejected — Mote: Floating ⌘. panel. snipnote is full-size by PRD §1; floating deferred to v5.
  • Rejected — Cursor 3.0 heavy IDE: LSP, debugger, git UI, multi-panel, AI chat.
  • Rejected — Notion complexity: Slash explosion, DB views, collaborative cursors, colored sidebars. LocalEditor anti-ref: “Fed up of notion's growing interface complexity.”
