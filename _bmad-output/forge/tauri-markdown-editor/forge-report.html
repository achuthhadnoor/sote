HARDENED

Forge Report: Full-Size Markdown Editor for Claude Code

Outcome

HARDENED for Build in Public — incremental to first dollar. Repositioned from "Unified Workspace (big bang)" to Full-Size Markdown Companion for Claude Code terminal lovers. Positioned vs Cursor 3.0 (heavy IDE) and Mote (floating native macOS-only, $19). Success = ship v1 simple editor fast, earn $1, then layer Canvas/Terminal/Floating sequentially.

Locked Decisions

  • Target: Claude Code customers who love terminal — not generic note-takers.
  • Form Factor: Full-size editor (not floating). Differentiates from Mote's tiny floating window; trades floating novelty for deep editing. Cross-platform via Tauri (Mote is macOS 15+ only).
  • Strategy: Build in public, one feature at a time. v1 = simple Markdown note editor.
  • Stack: Tauri v2 + Tiptap (WYSIWYG, Mermaid, todos). Excalidraw deferred to v2.
  • Data Model: Raw Markdown on disk is source of truth (AI DB). App parses to Tiptap and serializes back. Canvas JSON (v2) stays in separate files.
  • Roadmap (LOCKED ORDER): v1 Full-Size Editor → Obsidian vault compat → Canvas → Embedded Terminal (xterm + Rust PTY) → Floating notes.

Rejected Options

  • Big-bang Unified Workspace (Note+Canvas+Terminal Day 1): Rejected — too much scope for first dollar.
  • Floating-only v1 vs Mote: Rejected — direct attack on shipped native <150MB app.
  • Pure Native GPUI/Swift: Rejected despite Mote proving it's faster; Tauri kept for cross-platform + web ecosystem velocity.
  • Monaco as primary editor: Rejected — WYSIWYG priority for Claude's Markdown/Mermaid.

Surviving Weak Points

  • Serialization Fidelity: Still load-bearing — Tiptap must round-trip to clean Markdown without corrupting Claude's files. Needs tests from Day 1.
  • v1 Wedge: "Simple editor" is not a wedge vs Obsidian (free). Must nail Claude-specific file-watcher (no corruption when Claude writes mid-edit) + perfect Mermaid/todos.
  • Full-Size Competition: More crowded than floating (Obsidian, Typora, Bear). Story must be "Claude companion" not "another editor."
  • Incremental Architecture Debt: Adding Canvas/Terminal later requires core to support separate JSON files and PTY without rewrite.

Build-in-Public Roadmap

v1 (First $1): Tauri + Tiptap full-size, file-watcher, Mermaid/todos, vault folder open. Kill: Canvas, Terminal, Floating.

v2: Obsidian vault (frontmatter + folder). v3: Canvas toggle. v4: Embedded Terminal. v5: Floating window.
